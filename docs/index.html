Route → Apple Maps

Turn a Kurviger / GPX / KML route into a link that starts turn-by-turn navigation in native Apple Maps — CarPlay included. Everything runs in your browser; the route never leaves this device.

Choose a route file .kurviger · .gpx · .kml · .kmz — tap to browse

— or paste a route link —

Options

Apple Maps caps a route at ~15 stops; your current location counts as one.

Avoid

Starting a multi-stop route by hand is what fails on CarPlay (“Directions Not Available”) — leave this off to ride.

Default is your current location, which is what Apple Maps navigates from.

Open in Apple Maps

    Open on an iPhone (iOS 18.4+) standing at the route’s start — navigation begins on its own and CarPlay picks it up. Apple re-routes between stops, so the ride approximates the planned line.

    No upload, no tracking — parsing and conversion happen locally. Source on GitHub
