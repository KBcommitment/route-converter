# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Converts a planned navigation route (Kurviger `.kurviger`, GPX, KML/KMZ, or a
Kurviger/Google Maps link) into an Apple Maps unified directions URL
(iOS 18.4+) that starts multi-stop turn-by-turn navigation on iPhone and
CarPlay. Ships twice from one repo: a Python CLI and a static web app.

## Commands

```bash
# CLI (no install, zero dependencies)
python3 -m route_converter "sample/Aandalsnes - Trollstigen - Valldal.kurviger" --avoid highways

# Python tests (unittest — never pytest)
python3 -m unittest discover -s tests
python3 -m unittest tests.test_simplify.TestSimplify.test_hybrid_captures_detour_that_even_misses

# JS golden-parity tests (pass the file, not the directory)
node --test tests/js/test_converter.mjs

# Regenerate golden fixtures — REQUIRED after changing Python route logic
python3 tests/js/gen_fixtures.py

# Regenerate the synthetic sample routes
python3 sample/make_samples.py

# Serve the web app locally
python3 -m http.server 8899 --directory docs
```

## Architecture

Two parallel implementations of one pipeline — **parse → reduce checkpoints →
build URL** — kept honest by golden fixtures:

- `route_converter/` — the **Python reference** (stdlib only). `parsers/`
  handles each format and dispatches via `parse_source()` (extension first,
  then content sniffing); `simplify.py` reduces dense geometry to Apple's
  ~15-stop cap (`hybrid` places each stop on the point of maximum deviation
  within evenly sized arc-length cells, `even` spreads purely by distance;
  endpoints and `significant` waypoints always survive); `apple_maps.py`
  builds the URL.
- `docs/converter.js` — the **browser port** (single ES module, zero
  dependencies): same pipeline plus a minimal ZIP reader (KMZ via native
  `DecompressionStream`) and an XML element-tree abstraction (`DOMParser` in
  browsers, small fallback parser under Node). `docs/index.html` is the whole
  UI. GitHub Pages serves `docs/` from `main` — **pushing main deploys the
  live site**.
- **Parity is enforced, not assumed:** `tests/js/gen_fixtures.py` runs the
  Python CLI (`--json`) across all formats into
  `tests/js/fixtures/golden.json`; the Node tests replay them through the JS
  port (coordinates compared at 1.5e-6 tolerance). Changing route logic only
  on one side is a parity bug — change Python, regenerate fixtures, make JS
  match.

Behavioral invariants (verified on a real iPhone + CarPlay session — don't
"simplify" them away):

- **`start=0` in the URL is load-bearing.** Without it Maps opens a route
  preview whose multi-stop navigation cannot be started by hand (iPhone shows
  "Steps" instead of "Go"; CarPlay reports "Directions Not Available").
- Default origin is the rider's current location (no `source=`), which itself
  consumes one of the ~15 stops — the reduction budget is `maxStops − 1`
  unless `--source-at-start`.
- Kurviger/GraphHopper polylines can be **3-D** (lat, lon, elevation); the
  elevation flag must be honored or every coordinate after the first decodes
  garbled.
- `goo.gl` short links cannot be expanded client-side (CORS); the web app
  intentionally errors with a paste-the-expanded-URL hint. The Python CLI does
  expand them (network).
- **Route data cannot ride in a URL on iOS.** The app→browser handoff
  re-parses URLs and mangles large fragments (measured: a 34 KB fragment
  arrives truncated at its first `=` or stripped entirely), and query strings
  would hit the server, which the privacy design forbids. The share-sheet
  Shortcut therefore uses the clipboard + the page's paste button — the one
  tap is WebKit's user-gesture requirement for clipboard reads, not a UX
  choice. Don't "optimize" it back into the URL.

## Privacy rule (repo-specific, non-negotiable)

This repo is public and must contain **no personal data** — no real
home/route locations, no absolute home-directory paths (they embed the
machine's username), no personal or corporate email addresses, no device
identifiers — in files **or git history**. Sample
routes are synthetic (public landmarks only, generated by
`sample/make_samples.py`); keep them that way. The git identity for this repo
is pinned in local config to the repo owner's GitHub noreply address — never
commit here with any other identity. Sweep the tree and the commit metadata
for personal identifiers before every push (the session memory holds the
concrete checklist).
